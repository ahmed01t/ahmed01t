## Selected work

### [AI Codebase Assistant](https://github.com/ahmed01t/AI-CodeBase-Assistant) · Search and Q&A for GitHub repositories

Developers can explore a codebase, search for symbols, and ask questions that return streaming answers with file and line citations.

- Combined Tree-sitter parsing with vector retrieval so answers point back to the relevant source code.
- Automated GitHub synchronization and scoped repository access by tenant.

**Stack:** TypeScript · Next.js · Node.js · Express · Tree-sitter · PostgreSQL/pgvector

### Chatrio · AI commerce on WhatsApp

Customers can discover products, check inventory, and place orders in chat. Merchants can manage catalogs, track orders, and take over conversations from a dashboard.

- Built a multi-tenant backend and an asynchronous Redis/BullMQ pipeline to handle incoming WhatsApp messages.
- Used LangGraph and PostgreSQL vector search to ground product answers in each merchant’s catalog.

**Stack:** FastAPI · Next.js · TypeScript · PostgreSQL/pgvector · Redis · BullMQ · LangGraph
